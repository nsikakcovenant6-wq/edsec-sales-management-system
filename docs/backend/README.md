# Backend contract documentation

## Canonical sources
- OpenAPI: `/contracts/openapi.yaml`
- Prisma schema: `/prisma/schema.prisma`
- Prisma mirror: `/contracts/schema.prisma`
- Roles, permissions, security and owner decisions: `/contracts/role-permission-and-decisions.md`
- Changelog: `/contracts/CHANGELOG.md`

The `/docs/backend` files are human-readable documentation copies. Update canonical files under `/contracts` and `/prisma` first, then synchronize documentation copies in the same pull request.

The current v1.3 contract is a draft. Do not integrate against it until validation, Product Owner review and explicit stable status are complete.
